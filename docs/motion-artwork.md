# Rove motion artwork

The gold-loop artwork was generated with the built-in image generation tool, then encoded as a 1536 × 1024 WebP (about 67 KB) at `public/rove-gold-loop.webp`. No external stock footage or animation service is loaded. The route is an illustrative diagram, not a real map or live ride.

`app/journey-artwork.tsx` combines the artwork with native SVG route signals and CSS motion. The composition stays anchored in the page with softened edges and screen blending; there is no cursor tracking or visible playback control. Ambient light and route motion pause outside the viewport or when the browser tab is hidden. Reduced-motion preferences leave the static composition visible.
